# SceneTrace

## Опис проєкту

«SceneTrace» — RAG-система для пошуку інформації у сценаріях та діалогах фільмів. Система дозволяє знаходити релевантні фрагменти сценаріїв за запитами користувача, у тому числі коли назва фільму безпосередньо не вказана.

Основний сценарій використання — допомога студентам, сценаристам та фанатам кіно у пошуку сцен, діалогів, персонажів та сюжетних фрагментів у корпусі сценаріїв.

## Технологічний стек

* Python 3.11+
* ChromaDB - векторне сховище
* BAAI/bge-m3 - модель embeddings
* Llama 3.2 3B Instruct - генеративна модель

## Встановлення
1. Клонування репозиторію
git clone <URL_РЕПОЗИТОРІЮ> 
cd kino-detektiv
2. Створення віртуального середовища
python -m venv .venv
Активація у Windows:
.venv\Scripts\activate
Для Linux/macOS:
source .venv/bin/activate
3. Встановлення залежностей
pip install chromadb sentence-transformers transformers torch
4. Запуск
Після встановлення залежностей код системи буде розміщено в каталозі src/.
